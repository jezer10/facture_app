# FCTR — identidad visual oficial

Nombre público: **FCTR**, siempre en mayúsculas. Aprobado por el usuario: variante A de la exploración del 26 de septiembre de 2026.

## Símbolo

Tres barras horizontales alineadas a la izquierda y de longitud decreciente: una F abstracta. Barras de 32, 23 y 12 unidades de ancho; altura 9; separación vertical 5. Usar el SVG maestro y escalarlo proporcionalmente, sin redibujarlo ni alterar sus proporciones.

- [Símbolo maestro negro](../apps/billing-web/public/brand/fctr-symbol.svg).
- [Símbolo blanco](../apps/billing-web/public/brand/fctr-symbol-white.svg).
- [Composición horizontal](../apps/billing-web/public/brand/fctr-logo.svg).
- [Favicon adaptativo](../apps/billing-web/public/favicon.svg).

El nombre acompaña el símbolo en una sans serif geométrica de peso alto. La aplicación utiliza Manrope; el SVG horizontal conserva texto editable y requiere Manrope para reproducir exactamente la tipografía. El símbolo es vectorial y no depende de fuentes.

## Uso

Monocromo como versión principal, sin contenedor, sombras, degradados o contornos. Dejar alrededor un espacio libre mínimo equivalente a la altura de una barra. La versión blanca se usa sobre fondos oscuros. Mantener al menos 16 píxeles de alto para el símbolo aislado.

En el producto, FCTR es la marca principal. En el acceso compartido, la marca principal es **lbrnt**; el símbolo FCTR acompaña «Continuar a FCTR». Las alternativas de exploración son propuestas históricas, no versiones oficiales.

Este cambio afecta nombre e identidad visual. Se conservan nombres técnicos de repositorios, paquetes, client IDs y rutas existentes para no romper integraciones.
